# SKYCHARGE: EdgeHTML (Xbox One legacy Edge 18) checklist

Applies to **Path B, the backup EdgeHTML package** (`www-legacy/` → `layout-js/` → `SKYCHARGE_Backup_EdgeHTML_x64_<ver>.msix`; three **r162**, esbuild **ES2017**). **Path A, main WebView2** (`game-src/`, three r186, WebGL2, Chromium) is exempt from items 1–5 but still gets the console sweep and the perf budget. Never put the r186 build in the EdgeHTML app: it fails with "Error creating WebGL context" under WebGL1.

| # | Rule | Why | How it's checked | 1.0.6.0 result |
|---|---|---|---|---|
| 1 | **WebGL1 only.** No WebGL2-only APIs: no `getContext('webgl2')`-only code, `WebGL2RenderingContext`, GLSL `#version 300 es`, `texelFetch`, `gl_InstanceID`, `sampler2DArray`/`sampler3D`, DataArrayTexture/Data3DTexture, MRT, multisampled render targets. Instancing only via three (uses ANGLE_instanced_arrays) | Xbox One EdgeHTML exposes WebGL1 (ANGLE/D3D11) only | `rg -n "webgl2\|WebGL2RenderingContext\|#version 300\|texelFetch\|gl_InstanceID\|DataArrayTexture\|Data3DTexture\|sampler2DArray\|sampler3D" src/ game-src/`; custom shaders (`ShaderMaterial`, `onBeforeCompile`) reviewed by hand; headless `qa_headless.mjs <url> 1 1` (webgl2 → null) must render with `isWebGL2: false` | pass (headless only) |
| 2 | **No inline scripts or handlers.** Only external `<script src>`; no `<script>…</script>` bodies, no `on*=` attributes, no `javascript:` URLs | UWP local (ms-appx) context did not run inline scripts (1.0.0.0 black screen) | `rg -n "<script" www-legacy/index.html layout-js/index.html` (expect boot.js, shim.js, game.js only); `rg -n ' on[a-z]+="' *.html` | pass |
| 3 | **No OGG.** MP3/WAV only in the package; the loader must pick MP3 on EdgeHTML | EdgeHTML can't decode Ogg Vorbis | `unzip -l <msix> \| rg -i ogg` (expect none); `rg -n -i "\.ogg\|audio/ogg" src/ game-src/ www-legacy/` and review that each hit is a guarded probe | pass, with notes (BUG-010) |
| 4 | **No fetch() of local package files.** Use XHR (arraybuffer) or embedded data | fetch on ms-appx package files is unreliable on EdgeHTML | `rg -n "fetch\(" game-src/ www-legacy/game.js`; only the guarded fallback in sfx.js is allowed | pass (XHR patch, BUG-011) |
| 5 | **ES syntax/built-ins for Edge 18.** Built JS must be ES2017: no `?.`, `??`, `??=`/`\|\|=`/`&&=`, class fields, `#private`, static blocks, top-level await, BigInt, numeric separators, optional `catch {}`, object spread/rest, async iteration, dynamic `import()`; regex lookbehind, named groups, `/s` flag (flag these). ES2019+ **built-ins** are not polyfilled by esbuild: `Object.fromEntries`, `Array.prototype.flat/flatMap`, `String.prototype.matchAll/replaceAll`, `Promise.allSettled/any`, `globalThis`, `structuredClone`, `Array.prototype.at`, `Object.hasOwn`. Avoid them or polyfill them in shim.js | Edge 18 parser and runtime | `node qa_edge_scan.mjs www-legacy/game.js www-legacy/boot.js www-legacy/shim.js` (expect `TOTAL 0`); built-ins: `rg -o 'Object\.fromEntries\|\.flatMap\(\|\.flat\(\|\.matchAll\(\|\.replaceAll\(\|Promise\.allSettled\|Promise\.any\|globalThis\|structuredClone\|\.at\(\|Object\.hasOwn\(' www-legacy/game.js` and review each hit (three's `Ray.at()` is fine); runtime emulation `NO_FROMENTRIES=1 qa_headless.mjs` | **syntax pass; built-ins FAIL: `Object.fromEntries` (BUG-001)** |
| 6 | **Perf budget about 18–22 fps** on Xbox One (JS ≤ about 25 ms/frame), with auto step-down 1280x720 → 960x540 → 768x432 | GPU share and JIT limits on the console | On console: boot diag (`?diag=1`) `fps … js …ms`. Box: headless `renderer.info` draw calls/triangles as a trend vs the previous build (headless fps not representative) | headless only: ~264–289 calls, ~236–254k tris (BUG-004); console not measured |
| 7 | **Console sweep.** No page errors; console errors limited to known 404s | There's no devtools on the TV | `qa_headless.mjs` 20 s run, plus the on-screen `xbox-err` / boot diag on the console | pass (headless) |
| 8 | **TV/UX.** HUD inside the title-safe area (about 5%), text ≥ about 16 px at 1080p; B doesn't trigger system Back | TV viewing distance, overscan | index.html CSS review; on console | open (BUG-008) |
