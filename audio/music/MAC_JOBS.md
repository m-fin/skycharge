# SKYCHARGE music as ffmpeg-only Mac jobs (no Python on the Mac)

Generated by `gen_jobs.py` on the shared computer. It writes text only; nothing is synthesized there.
After any change, re-run `python3 gen_jobs.py`. **Nothing has been rendered or listened to yet, and nothing has been submitted.**
Submitting needs Frog's OK.

The pattern is the same as DRIFTHOME M2 (`/workspace/sonic-rift/game/premiere/m2ffmpeg/`). Each job is plain `ffmpeg` with
`{in:..}`/`{out:..}` placeholders. All 6 cmd arrays pass `rh_common.validate_job` from m-fin/render-helper
(checked locally, without submitting). The filtergraphs are files (`jobs/<cue>.fg`) passed with `-/filter_complex`, which needs ffmpeg 7+.
They use only `aevalsrc`, `anoisesrc` (fixed seeds), `aiir` (one-pole low/high-pass), `volume`, `adelay`,
`amix`, `amultiply`, `asplit`/`concat` (3× periodic copy), `aecho`, `atrim`, `apad`, `asetpts`.

## Per cue: 3 jobs (the cmd arrays are in `jobs/<cue>.json`)
1. **A_synth**: input `<cue>.fg`, output `<cue>_raw.wav` (mono, 32-bit float, exact loop length in samples).
2. **B_measure**: input `<cue>_raw.wav`, loudnorm pass 1 (`I=-16:TP=-1.5:LRA=11`), `-f null -`.
   It writes no output file. The JSON stats land in the job log (`done.json` → `log_tail`).
3. **C_finalize**: on the box, save B's log to a file, then run
   `python3 fill_pass2.py jobs/<cue>.json b_log.txt`. That prints the filled pass-2 cmd (`linear=true`, OGG Vorbis q5,
   44.1 kHz mono). It exits 2 with a warning if linear mode can't hold: either the peak would pass −1.5 dBTP (lower I in the
   cmd) or the LRA is over 11 (raise LRA). Check that the pass-2 log says `"normalization_type" : "linear"`.
   **Never ship a loop in dynamic mode.** Dynamic mode changes gain over time and breaks the seamless wrap.

Return the OGGs to `/workspace/crave-lab/plane-game/audio/music/out/` (the test page and README expect that path).

## How the loops stay seamless
- The loops are whole bars and whole samples (128.0 s = 5644800 samples at 44.1 kHz for both).
- Full-length tones use frequencies snapped to a whole number of cycles per loop. The drum patterns are one periodic bar expression, and the section
  envelopes are periodic over the loop.
- Note tails that run past the end are wrapped to the start (`place()`).
- Echoes and noise filters run on a 3× periodic copy, and the middle copy is kept, so the echo/filter state at the end matches the start.
- Finalize uses linear loudnorm only (a constant gain).
